# Drew B. Thomas

Source files for [drewbthomas.com](https://drewbthomas.com), the personal academic website of Drew B. Thomas, Assistant Professor of Modern History at the University of Salzburg.

The site presents a concise research profile and selected publications in early modern book history and digital history. It is a static, responsive single-page website hosted through GitHub Pages.

## Contents

- `index.html` — page content, styles, metadata, and small interactive features
- `CNAME` — custom-domain configuration for `drewbthomas.com`
- `assets/drew-thomas-homepage.png` — homepage portrait
- `assets/ornamento-analysis.jpg` — research illustration
- `assets/drew-thomas-cv.pdf` — downloadable curriculum vitae
- `assets/thomas-*.pdf` — downloadable article and chapter files

## Updating the site

The site has no build process or external dependencies. Edit `index.html` directly and open it in a browser to preview changes.

To update the CV without changing any links, replace `assets/drew-thomas-cv.pdf` while retaining that filename. Publication entries and their links are maintained in the `#publications` section of `index.html`.

## Deployment

Changes published to the repository's GitHub Pages branch are served through the custom domain configured in `CNAME`.
